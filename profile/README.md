## 我们是谁

InfinAngle 是一支以 **驻场交付** 为核心工作方式的 AI Agent 团队。
不做 PPT 咨询，不卖标准化 SaaS —— 我们进到客户业务里，从真实工作流开始，把 Agent 真正跑起来。

- **驻场式 FDE**：工程师直接在业务方一线工作，从摸需求到上线闭环
- **切片交付**：每一次都以"能跑通的最小可用切片"为目标，而不是文档和演示
- **技术自主**：从 Agent 编排、前端体验、后端服务到评测体系，全链路自己动手

## 工作方式

| 阶段 | 我们做什么 | 交付物 |
|------|-----------|--------|
| **摸需求** | 驻场访谈、影子跟随、工作流拆解 | 需求切片图谱 |
| **搭切片** | 端到端最小可用版本，跑通真实流程 | 可用 Demo |
| **上一线** | 内测、灰度、A/B、指标回收 | 上线版本 + 指标 |
| **迭代深化** | 沿业务瓶颈继续深挖 | 长期驻场 |
